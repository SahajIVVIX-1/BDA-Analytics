# Sample data

`ira_sample_1000.csv`: the first 1,000 rows of `IRAhandle_tweets_7.csv` from FiveThirtyEight's
[russian-troll-tweets](https://github.com/fivethirtyeight/russian-troll-tweets) dataset (Linvill and Warren,
Clemson University), redistributed unchanged under CC BY 4.0. Use it to try the upload page or
`python scripts/ingest.py data/sample/ira_sample_1000.csv --profile ira538 --db social_analytics_demo`
without downloading the full dataset.
